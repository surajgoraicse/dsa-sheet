# Greedy — Problem Sheet

## Patterns Reference

| Pattern | Core Learning Objective & Intuition | Prerequisites | Priority |
|---|---|---|---|
| Activity Selection / Interval Scheduling | Master the core greedy proof pattern: sort by a key (end time) and greedily pick whichever choice preserves the most future options. | Sorting | 🔥 High |
| Greedy on Sorted Ratios (Fractional Knapsack style) | Sort items by value-per-unit-cost and consume the highest-ratio items first. | Sorting | 🔥 High |
| Jump Game / Reachability Greedy | Track the farthest reachable index seen so far while scanning. | Arrays basics | 🔥 High |
| Greedy Exchange Argument Problems | Learn to justify a greedy choice by proving any optimal solution can be transformed into the greedy one. | Sorting | ⚡ Medium |
| Two-Pointer Greedy (Gas Station, Candy style) | Combine greedy local decisions with a single-pass pointer sweep. | Two Pointers, Prefix Sum | 🔥 High |
| Heap-Based Greedy Scheduling | Use a heap to always process the "currently most urgent/valuable" task. | Heap/Priority Queue | 🔥 High |
| Greedy + Interval Merging/Partitioning | Merge or partition overlapping intervals via sorting on start/end. | Interval Scheduling | 🔥 High |
| Greedy String/Array Construction | Build the lexicographically smallest/largest result by greedily deciding each position. | Monotonic Stack | ⚡ Medium |
| Greedy vs. DP Boundary Recognition | Recognize when a problem that looks greedy actually requires DP. | DP basics, Greedy basics | 🔥 High |
